# 1608 — page publique

Page d'attente de la marque MILLE-SIX-CENT-HUIT publiée à l'adresse https://1608qc.com/.

Ce dépôt contient uniquement les fichiers nécessaires à la page publique et un lien de gestion via GitHub. Aucune commande ni aucun paiement n'est accepté.

**Important :** tout dépôt public GitHub et tout site statique public donnent accès aux fichiers livrés au navigateur. Pour garder le code propriétaire privé, utiliser un dépôt source privé distinct du dépôt de publication. Le dépôt actuel et son historique ne deviennent pas confidentiels par une simple suppression de fichiers sur `main`.

Le fichier `admin.html` ne gère aucun mot de passe. Il dirige l'équipe vers l'authentification officielle de GitHub.
